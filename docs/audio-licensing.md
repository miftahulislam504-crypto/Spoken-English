# Audio licensing policy

Current state: every clip is produced on the learner's phone by the built-in text-to-speech voice (`audio_source: "device-tts"`). No audio files are stored or distributed, so no audio licence is needed.

Before any recorded or generated audio file is added:
1. Record the source, speaker, accent, licence and date in the clip metadata (`audio_source`, `speaker`, `accent`, `license`).
2. Use only audio we recorded ourselves with a signed speaker release, or audio under a licence that allows commercial use in a paid app.
3. Do not use clips copied from films, songs, news, podcasts or other apps.
4. Keep the licence evidence with the content record so it can be shown on request.
5. Review any third-party text-to-speech terms for commercial use and for storing generated audio.
